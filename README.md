# File Management App in Python

This is a **File Management Application** built with Python, designed to perform basic file operations such as creating, viewing, deleting, reading, and editing files in the current working directory. The app features a command-line interface that is simple to use and provides essential functionalities for managing files.

## Features:
- **Create File**: Creates a new file in the directory.
- **View All Files**: Lists all files in the current directory.
- **Delete File**: Deletes a specified file.
- **Read File**: Displays the content of a file.
- **Edit File**: Appends new content to an existing file.
- **Error Handling**: Handles errors gracefully, such as file not found or file already exists.
- **Command-Line Interface**: Interactive menu for easy navigation.

## How to Use:

1. **Clone or download** this repository to your local machine:
   ```bash
   git clone https://github.com/Its-Vikas-xd/File-Management-App.git
   ```
2. Navigate to the project directory:
   ```bash
   cd File-Management-App
   ```
3. **Run the application** using Python:
   ```bash
   python file_management_app.py
   ```
4. Follow the on-screen instructions to interact with the app.

## Requirements:
- Python 3.x
- Basic understanding of file handling in Python
